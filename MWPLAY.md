# MW Play

**Seu mundo em streaming.**

MW Play is an independent interface project based on the open-source Stremio Web client. The project keeps the upstream streaming/client architecture while introducing a distinct MW Play visual identity and user experience.

## Brand direction

- Deep cinema-black surfaces
- Purple → electric-blue gradient accents
- Cleaner, softer cards and focus states
- Responsive experience for desktop, mobile and TV-sized displays
- MW Play identity separated from the upstream Stremio brand

## Development

```bash
pnpm install
pnpm start
```

Production build:

```bash
pnpm build
```

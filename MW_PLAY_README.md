# MW Play

MW Play is an independent streaming-client UI project built from the open-source Stremio Web codebase.

The redesign goal is a darker, cleaner, TV-friendly experience with an original MW identity while retaining the mature account, addon-protocol and playback foundations of the upstream client.

See `MW_PLAY_STATUS.md` for current progress and `MW_PLAY_UI_SPEC.md` for the target experience.

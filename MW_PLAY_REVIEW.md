# Review checklist

Before merging the redesign into `main`:

- [ ] Production build succeeds
- [ ] Login/account flow still works
- [ ] Existing addon protocol behavior still works
- [ ] Library and Continue Watching synchronize normally
- [ ] Video playback starts and seeks normally
- [ ] Audio/subtitle controls work
- [ ] Mobile layout is usable
- [ ] Desktop keyboard navigation is usable
- [ ] TV/remote focus states are visible
- [ ] Remaining visible Stremio branding is reviewed and replaced where legally/technically appropriate
- [ ] MW Play icons exported to required PWA/favicon formats

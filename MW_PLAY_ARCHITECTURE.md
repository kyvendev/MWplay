# MW Play architecture boundary

## Preserve
- Stremio Core Web integration
- Account synchronization
- Addon protocol compatibility
- Library and playback state
- Video player capabilities
- Casting/subtitle/audio plumbing

## Customize
- Product name and metadata
- Logo, icons and splash identity
- Color, typography, spacing and focus treatment
- Navigation presentation
- Home/discovery hierarchy
- Details/episode presentation
- Player chrome
- TV interaction polish

This boundary keeps the first redesign focused on UX while reducing the chance of breaking mature playback/account behavior.
